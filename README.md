# Cool 3D Wallpaper 
I wanted to have a cool 3D model with particles and fancy effects as a wallpaper, so I made this.

It is a website that displays various 3D models, and if you want to use it as a wallpaper, you need an external application like : [Octos](https://github.com/underpig1/octos) or [Lively](https://github.com/rocksdanister/lively)

## How does that work 
I have no idea, I vibe coded nearly everything 😶. 

But if you want to add your own 3D models and effects, you can try messing around with the `config.json` file. It should be pretty easy to use.

## Feature 
- Particle effects
- Gradient background
- Real-time (kind of) editor
- Support for 3D animations
